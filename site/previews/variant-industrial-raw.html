The bench

The same construction shush uses to seal your vault, running in this tab: Argon2id stretches a password into a key, AES-256-GCM seals the text, and the tag catches any change to a single bit. Nothing you type leaves the page.

Argon2id via hash-wasm, AES-GCM via WebCrypto. In the app this runs in Rust, and the key is zeroized when the vault locks.

Hardened on Windows

What shush does when the machine around it changes state.

eventshush
Win+L, sign-outLocks the vault and wipes the derived keys from memory.
sleep, display offLocks before the machine suspends or the screen goes dark.
idle timeoutLocks after a period without input.
screen captureThe window is excluded from screenshots and recordings.
copy a passwordKept out of clipboard history and cloud clipboard, then cleared.
second launchFocuses the running instance; one process owns the vault file.
Ctrl+Alt+SpaceQuick search from any app. A window title can pre-select a login but never triggers typing.

Build it

Alpha, Windows 10/11. Needs Rust (stable), Node 22 and the WebView2 runtime.
